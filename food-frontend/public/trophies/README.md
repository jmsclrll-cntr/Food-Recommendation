# Custom Medal & Trophy Images Folder

Place your 5 custom medal or trophy images in this folder. To make them work with the Diet Achievement dashboard widget, please use these exact filenames:

1. **`beginner.png`** - Used for the "Beginner" tier (0 - 6 completed days total).
2. **`consistent.png`** - Used for the "Consistent" tier (7 - 13 completed days total).
3. **`dedicated.png`** - Used for the "Dedicated" tier (14 - 20 completed days total).
4. **`champion.png`** - Used for the "Champion" tier (21 - 27 completed days total).
5. **`legendary.png`** - Used for the "Legendary" tier (28+ completed days total).

Supported format: **PNG** (recommended to use transparent backgrounds for a beautiful claymorphic premium look).
